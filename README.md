# NINNA Backend

API base para autenticação, rotina, sincronização e relatórios.

## Scripts

```bash
npm install
npm run dev
npm run build
npm run start
```

## Endpoints

- `GET /health`
- `POST /api/auth/register`
- `POST /api/auth/login`
- `GET /api/babies`
- `POST /api/babies`
- `GET /api/records`
- `POST /api/records`
- `GET /api/reports/pediatric`
- `GET /api/premium/features`
